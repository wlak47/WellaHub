EXPLAINED IN PLAIN WORDS

What Wella Hub does.

Wella Hub is a Windows app for viewing and managing parts of your Steam setup. You can explore the sample screens first; you only connect an account when you choose to.

01

Hour Booster

Choose a Steam account and the games you want to show as running. See time for the current session and the total time recorded for each game. Start or stop the booster when you want.

02

Achievement Manager

Browse games in an account and see their achievement progress. The tools in this section can change achievement status, so use them only on an account you control and review your selection first.

03

Free Games

Browse free-to-play games and current free offers. Search the list, open a game’s Steam store page, or try adding an offer to the account you select. Steam decides which offers are claimable.

04

Phone website and PC controls

Open the web address shown in Settings on your phone to view the PC dashboard. Depending on your settings, you can manage boosts, launch installed games, view the PC screen and use remote controls.

05

Monitor and FPS tools

See PC and game performance information when the related monitor is enabled. Some FPS details depend on the game and the monitoring tool available on your PC.

06

Web device manager

Review browsers that have connected to your PC. You can disconnect or remove a device, block it, or whitelist a device you trust so it does not ask for the web password each time.

GUIDE 01 · WINDOWS

Install and explore the desktop app

About 5 minutes · Windows 10 or 11

Get the installer ↓
  1. Download Wella Hub.Choose “Download for Windows” above. The installer is also available in website/applicatzion.
  2. Wait for the download to finish.Keep the full Wella Hub Setup.exe file; it is a large installer.
  3. Open the installer.Double-click the downloaded file. If Windows asks whether to run it, check that the filename is Wella Hub Setup.exe, then continue.
  4. Choose where it belongs.Follow the setup window and choose an install location if it asks. Keep enough disk space available.
  5. Let setup complete.Wait for the progress bar to finish before closing the installer.
  6. Start Wella Hub.Open it from the desktop shortcut or Start menu. Leave it running while you use its local features.
  7. Look around in demo mode.Use the tabs to inspect Hour Booster, Achievement Manager and Free Games. The website preview needs no account.
  8. Add your Steam account when ready.Use the app’s account flow and complete Steam’s sign-in or confirmation steps yourself. Never share your Steam password with anyone.
  9. Choose what to show.Pick an account and its selected games. Check the session and total-playtime figures before starting a boost.
  10. Keep the app updated.Return to the download page when you want a newer installer. Close Wella Hub before installing an update.
Tip: the desktop preview above is interactive. Click a tab to see example screens without connecting an account.
GUIDE 02 · PHONE BROWSER

Open your PC dashboard on your phone

About 7 minutes · Keep Wella Hub open on the PC

PC + PHONE
  1. Install Wella Hub on the PC.Complete the desktop guide first and open the app on the computer you want to access.
  2. Open Settings in Wella Hub.Find the Web access section. The PC app must stay open for the phone view to work.
  3. Enable web access.Switch on “Enable web access” on the PC. Keep the setting off when you do not need remote access.
  4. Set a strong web password.Create a unique password of at least eight characters in the app. Do not reuse your Steam password.
  5. Allow private network access if asked.When Windows Firewall prompts you, allow Wella Hub on private networks you trust.
  6. Choose a connection link.For home Wi-Fi, use the same-network address shown in Settings. For access away from home, use the public link only if you have enabled it.
  7. Open the link on your phone.Type or copy the address into your phone’s browser. On the same Wi-Fi, connect your phone to that network first.
  8. Sign in to the web dashboard.Enter the web password you just created. Whitelist a personal device only if you want to skip the password on that device.
  9. Use the controls carefully.Check the selected account before starting or stopping a game or boost. The phone controls the PC while the web session is active.
  10. Finish safely.Sign out on shared phones, disable web access when finished, and close Wella Hub on the PC to end the session.
Connection links and available controls depend on the web-access settings currently shown by your desktop app.
FIND ANY SCREEN

Guides for every tab and setting.

Open a section to see where to click and what each screen does.

Main tabs and tools

Hour Booster

Where: Top bar → Hour Booster. Choose an account from the left rail.

Start or stop one account, or use Start all/Stop all. Account cards show session time, total boosted time, card drops and selected games. Click a game for details; use the pencil to choose games.

Achievement Manager

Where: Top bar → Achievement Manager; choose an account and then a game.

Search the library, inspect progress and select achievements. Bulk actions can change achievement status on the connected account, so check your selection before applying.

Free Games

Where: Top bar → Free Games → Browse games or Auto discovery.

Browse and search games, sort results, choose an account and open a store listing. Auto discovery lets you set offer types, accounts, a name filter, check interval and review history.

Utility

Where: Top bar → Utility, then choose a tool chip.

Player Stats looks up a profile; Profile Compare and Compare players compare public profiles; Inventory shows public inventory; Account Health summarizes account signals. Other chips open Password Generator, Speed Test, Rank history, Badges, Steam sales, Daily report, PC health, Webhook, YouTube and Timings. Some tools need an API key or public profile data.

FPS Monitor and Monitor

Where: Gear → General → Tabs & monitor. Turn on the tabs, then open them from the top bar.

FPS Monitor shows supported game frame-rate data. Monitor shows PC readings such as CPU, GPU, memory and disk. Alert thresholds are in monitor settings.

Remote PC

Where: Gear → Web access. Enable access, then open the phone link and choose Remote PC.

Choose a display, quality and frame rate, then start sharing. Use touch, keyboard shortcuts or the text box to control the PC. The website preview simulates these controls.

Global search and account details

Where: Click the magnifying glass near Settings. Search for a tab, tool, account, action or game.

Click an account name to open its profile information. Click a game row to open game details and available actions.

Settings → General

Appearance

Where: Gear → General → Appearance.

Choose language, theme, accent colour, font, text size, corner style and theme presets. The interface language applies to available translated labels.

Background

Where: Gear → General → Background.

Choose a built-in background or upload one. Adjust blur, visibility, darkness, saturation, colour shift, zoom, fit, position and movement. Reset sliders to restore defaults.

Buttons

Where: Gear → General → Buttons.

Set colours for primary, Start and Stop buttons with presets, the colour picker or a hex value. Reset to default colours any time.

Notifications

Where: Gear → General → Notifications.

Choose the notification shape, preview it, enable desktop notifications and sound, adjust volume, choose event alerts, and try Test notification/Test alert.

Tabs & monitor

Where: Gear → General → Tabs & monitor.

Show or hide FPS Monitor, Monitor, Utility and Free Games in the top navigation.

Startup

Where: Gear → General → Startup.

Choose whether the app starts with Windows, Hour Booster starts automatically, and Free Games discovery starts automatically.

Mini widget

Where: Gear → General → Mini widget.

Enable the compact widget and adjust its size, opacity, position and accent. Close it from its own controls.

API keys

Where: Gear → General → API keys.

Add or remove optional Steam, FACEIT or Leetify keys for tools that use them. Keep keys private; the website demo does not save or send keys.

Settings → Discord and Web access

Discord Rich Presence

Where: Gear → Discord.

Enable Rich Presence, set the Discord Application ID and display name, edit the two status lines, preview them and choose whether total hours are added automatically. Auto setup fills the basic fields.

Web access

Where: Gear → Web access.

Enable the web service, set its password and port, and copy a same-network address for your phone. The optional public link can be managed here when available.

Connected devices

Where: Gear → Web access → Web Device Manager.

Refresh the device list, whitelist or unwhitelist a device, block or unblock it, disconnect its session, or remove its record.

Phone access and demo preview

Open the phone website

Where: PC app → Gear → Web access; phone browser → copied address.

Keep the PC app open, sign in with the web password and use the navigation available to that session. Settings and account menus stay available from their icons.

Preview mode

Where: Preview → Desktop app or Phone website.

The preview uses sample accounts. Its buttons do not start a real boost, launch games, change achievements, claim offers, share your screen or control your PC. Browser alert boxes are replaced with small in-app preview messages.
